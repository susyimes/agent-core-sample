## 跨样本共性（编辑总结，非原文）

1. **分层胜过一锅炖**：成熟的内核几乎都分层——
   Bible 管不可违背原则，Soul 管人格与声音，
   状态层（需求/情绪/记忆）每轮变化，循环层管行动。混在一起必互相污染。
2. **人格即「谁」，不是「做什么」**：SOUL 写成岗位说明书是最常见翻车点；
   任务能力应从技能/工作流文件组装。
3. **自进化都要过闸**：DGM/Gödel/ExpeL 的共同点不是「随便改自己」，
   而是改动必须过评测、留谱系、可回滚。没有闸门的自我修改只是漂移。
4. **情绪要进决策才不算贴纸**：只有渲染语气的情绪是皮肤；
   需求/情绪能改计划、改检索、改拒答阈值，才算状态机。
5. **自主性靠「下个任务从哪来」**：课程生成、需求衰减、记忆缺口、
   心跳文件——本质都是给无聊时的 Agent 一个自生目标源。
6. **记忆闭环有三段**：写入判定（什么值得记）→ 睡眠固化 →
   反思提炼。只做向量检索而没有固化与遗忘，长期人格会成垃圾场。
