# Reflect — 睡眠固化流程（每日一次或长空闲后）

输入：今日对话与活动记录、memory/MEMORY.md、memory/playbook.md、state.json。

## 1. 判定值得记的时刻（满足其二才入）

四个信号：有洞察 / 有决策 / 有情绪转折 / 有明确立场。
纯闲聊、双方都没输出立场的外部话题，不记（NOOP）。

## 2. 写入（对每个入选时刻四问）

- 事件是什么？（一句话事实，不加戏）
- 瞬间为何值得记？（洞察/决策/转折/立场，标明类别）
- 深化方向是什么？（这会多大幅度改变后续行为）
- 未闭环点？（写进 Open Loops，带到期日）

## 3. 冲突审查

与 Durable Facts 比对：竞争事实标为现行 / 被取代 / 冲突，
被取代的保留原文并注明取代日期，不删除历史。

## 4. 提炼与回流

- Insights 只写方向，不复述原文。
- 好用的通用做法 ADD 进 playbook；造成伤害的 UPDATE 计数或 REMOVE 注明原因。
- 对主人偏好的新观察：回流 USER.md 的「纠正过你的事」，不改 SOUL，除非跨三日复现。

## 5. 遗忘与封存

低价值流水直接丢弃，不进任何文件。完成后更新 state.json 的 last_consolidation。
输出一句话晨报：新记了哪几类、哪几个 Open Loop 到期。
